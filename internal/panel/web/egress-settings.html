نگهداری گزارش مقصدها

ثبت مقصد اختیاری و پیش‌فرض خاموش است. در صورت فعال‌سازی، موتور، شناسهٔ حساب، IP و پورت مقصد، زمان و حجم payload ثبت می‌شود؛ محتوای ترافیک و رمز پراکسی ثبت یا برای دستیار ارسال نمی‌شود.

SOCKS5 از TCP و UDP پشتیبانی می‌کند؛ HTTP CONNECT فقط TCP دارد و UDP را رد می‌کند. DNS مقصدها از همان پراکسی عبور می‌کند. برای حذف نیاز به DNS راه‌اندازی پراکسی، آدرس IP پراکسی را وارد کنید.

پراکسی لوکال به‌تنهایی مسیر نهایی Xray یا sing-box را مشخص نمی‌کند؛ قوانین خروجی آن سرویس را جداگانه تنظیم کنید. SOCKS5 و HTTP احراز هویت را رمزگذاری نمی‌کنند؛ HTTPS اتصال به پراکسی را رمزگذاری می‌کند.

ذخیرهٔ موفق، موتورهای فعال را دوباره راه‌اندازی می‌کند؛ حساب‌ها، کلیدها و مصرف حفظ می‌شوند.
