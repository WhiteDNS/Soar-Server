# WhiteDNS Server Management 1.16.1

این نسخهٔ آزمایشی امکان ارائهٔ کانفیگ رایگان را به ربات تلگرام پنل اضافه می‌کند. مدیر از منوی `/admin` می‌تواند پلن‌های Soar، CottenDNS و MasterDNS، سهمیه و اعتبار، تأیید درخواست‌ها و پیام‌های همگانی را مدیریت کند. کاربران از منوی `/start` درخواست می‌دهند و پس از تأیید، لینک و QR موتورهای حساب خود را دریافت می‌کنند.

- دسترسی عمومی در ابتدا خاموش است. مدیر می‌تواند پذیرش درخواست تازه را متوقف کند یا از توقف اضطراری برای بستن مسیر عمومی ربات استفاده کند.
- پاسخ یک‌بارمصرف، تأیید مدیر، سقف صف و صدور، و پردازش جداگانهٔ درخواست‌های عمومی از ساخت انبوه حساب محافظت می‌کنند.
- پس از نصب، از بخش «کانفیگ رایگان» شروع کنید. [راهنمای ربات](https://github.com/WhiteDNS/Soar-Server/blob/panel-v1.16.1/docs/TELEGRAM.md)

### نصب نسخهٔ آزمایشی

روی سروری که پنل با systemd نصب شده، این دستور بستهٔ امضاشدهٔ `1.16.1` را نصب می‌کند. سرویس نگهداری در زمان نصب پنل را موقتاً راه‌اندازی مجدد می‌کند و برای شکست فعال‌سازی نسخهٔ قبلی را بازیابی می‌کند.

```bash
sudo /usr/local/bin/soar-panel maintenance --action update --version 1.16.1
```

برای Docker Compose، در پوشهٔ نصب اجرا کنید.

```bash
SOAR_PANEL_VERSION=1.16.1 docker compose up -d --pull always
```

برای استفادهٔ مداوم از این نسخه در Docker، مقدار `SOAR_PANEL_VERSION=1.16.1` را در فایل `.env` نصب ذخیره کنید. نصب‌کنندهٔ عادی، اعلان‌های پایدار و تگ Docker `latest` همچنان نسخهٔ پایدار را دنبال می‌کنند.
