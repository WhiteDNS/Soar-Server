# WhiteDNS Server Management 1.16.2

این نسخهٔ آزمایشی مسیر درخواست و مدیریت کانفیگ رایگان را در ربات تلگرام ساده‌تر می‌کند.

- پس از فعال‌شدن دسترسی عمومی، دکمهٔ «منو» در گفت‌وگوی خصوصی کاربر میان‌برهای درخواست، حساب، راهنما و زبان را نشان می‌دهد.
- جابه‌جایی بین منوها همان پیام را ویرایش می‌کند. دکمه‌های رنگی، متن‌های فارسی و مسیر «حساب من» پیگیری درخواست و دریافت لینک و کد QR را آسان‌تر می‌کنند.
- مدیر در داشبورد به درخواست‌ها، پلن‌ها و موتورها، حساب‌ها، آمار، پیام همگانی و تنظیمات عمومی دسترسی دارد. حجم، مدت و محدودیت‌های پلن فیلدبه‌فیلد ویرایش می‌شوند.
- درخواست‌های تازه در اعلان‌های گروه‌بندی‌شده به گفت‌وگوی خصوصی مدیر می‌رسند. هر اعلان دکمهٔ «مشاهدهٔ درخواست‌ها» دارد.

آزمون‌های خودکار با استفادهٔ مجدد از هش آزمایشی سریع‌تر اجرا می‌شوند. پوشش آزمون‌ها شامل ورود، ساخت حساب مدیر با هزینهٔ bcrypt واقعی و بازیابی پشتیبان است.

### نصب نسخهٔ آزمایشی

برای نصب systemd، دستور زیر بستهٔ امضاشده را بررسی و نصب می‌کند. هنگام راه‌اندازی مجدد، اتصال‌ها ممکن است موقتاً قطع شوند.

```bash
sudo /usr/local/bin/soar-panel maintenance --action update --version 1.16.2
```

برای Docker Compose، در پوشهٔ نصب اجرا کنید.

```bash
SOAR_PANEL_VERSION=1.16.2 docker compose up -d --pull always
```

برای ماندن روی این نسخه در Docker، مقدار `SOAR_PANEL_VERSION=1.16.2` را در فایل `.env` نصب ذخیره کنید. دریافت این نسخه با انتخاب شمارهٔ آن انجام می‌شود.
