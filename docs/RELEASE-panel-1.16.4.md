# WhiteDNS Server Management 1.16.4

- منوی عمومی تلگرام صف جدا دارد. تکرار `/start` از یک چت در زمان انتظار، نوبت اضافه نمی‌گیرد. هنگام ازدحام، ربات در حد ظرفیت ارسال زمان تلاش دوباره را اعلام می‌کند.
- مدیریت ربات، پاسخ به تأیید فعال و دریافت کانفیگ موجود از صف منوی عمومی جدا هستند. محدودیت‌های ثبت درخواست و صدور کانفیگ همچنان اعمال می‌شوند.
- ارسال پیام در محدودهٔ رایگان تلگرام انجام می‌شود. هنگام محدودیت ارسال، صف منو پس از مهلت تعیین‌شدهٔ تلگرام ادامه پیدا می‌کند.
- در آزمون شبیه‌سازی‌شدهٔ ۵۰۰ کاربر، همهٔ منوها در حدود ۲۵ ثانیه ارسال شدند. زمان پاسخ روی سرور واقعی به ظرفیت تلگرام و شرایط شبکه بستگی دارد.

### نصب پیش‌انتشار

روی سروری که پنل با systemd نصب شده، این دستور را اجرا کنید.

```bash
sudo /usr/local/bin/soar-panel maintenance --action update --version 1.16.4
```

برای Docker Compose، دستور زیر را در پوشهٔ نصب اجرا کنید.

```bash
SOAR_PANEL_VERSION=1.16.4 docker compose up -d --pull always
```

برای ثابت‌کردن نسخهٔ Docker، مقدار `SOAR_PANEL_VERSION=1.16.4` را در فایل `.env` نصب ذخیره کنید.
