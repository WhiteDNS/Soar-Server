# WhiteDNS Server Management 1.16.7

- مالک ربات می‌تواند از «داشبورد کانفیگ رایگان ← دسترسی و متن‌های عمومی ← عضویت اجباری» شرط عضویت در حداکثر پنج کانال یا گروه را تنظیم کند. ربات باید در چت‌های انتخاب‌شده ادمین باشد.
- وقتی این شرط فعال است، ربات لینک عضویت و دکمهٔ بررسی دوباره را نشان می‌دهد. عضویت پیش از ثبت و صدور کانفیگ رایگان بررسی می‌شود.
- اعلان، فهرست و جزئیات درخواست، نام کاربری موجود تلگرام را کنار شناسهٔ عددی نشان می‌دهند.

### نصب پیش‌انتشار

روی سروری که پنل با systemd نصب شده، این دستور را اجرا کنید.

```bash
sudo /usr/local/bin/soar-panel maintenance --action update --version 1.16.7
```

برای Docker Compose، دستور زیر را در پوشهٔ نصب اجرا کنید.

```bash
SOAR_PANEL_VERSION=1.16.7 docker compose up -d --pull always
```

برای ثابت‌کردن نسخهٔ Docker، مقدار `SOAR_PANEL_VERSION=1.16.7` را در فایل `.env` نصب ذخیره کنید.
