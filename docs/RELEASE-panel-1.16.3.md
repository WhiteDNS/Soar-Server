# WhiteDNS Server Management 1.16.3

- دکمه‌های تلگرام رنگ‌بندی یکدست دارند. آبی برای مرور و بازگشت، سبز برای افزودن و تأیید، و قرمز برای رد، حذف، توقف و کارهایی مانند راه‌اندازی مجدد است.
- مالک از «داشبورد کانفیگ رایگان ← مدیران ربات» می‌تواند ادمین اضافه کند، نقش او را تغییر دهد یا دسترسی‌اش را لغو کند. دو نقش «مدیر کانفیگ رایگان» و «مدیر کامل ربات» در دسترس‌اند. مدیر کامل به پشتیبان‌ها و کلید بازیابی هم دسترسی دارد.
- در «حساب‌ها ← مدیریت کاربر تلگرام»، مدیر می‌تواند وضعیت حساب و مهلت درخواست را ببیند. برای کانفیگ حذف‌شده یا درخواست رد یا لغوشده، می‌تواند اجازهٔ یک درخواست زودتر بدهد یا پیش از استفاده آن را لغو کند.
- پیام‌های مسیر درخواست، علت محدودیت و قدم بعدی را توضیح می‌دهند. اعلان درخواست‌های تازه برای هر مدیر جداگانه ارسال می‌شود.

### نصب نسخهٔ آزمایشی

برای پنل نصب‌شده با systemd:

```bash
sudo /usr/local/bin/soar-panel maintenance --action update --version 1.16.3
```

برای Docker Compose، در پوشهٔ نصب:

```bash
SOAR_PANEL_VERSION=1.16.3 docker compose up -d --pull always
```

برای ماندن روی این نسخه در Docker، مقدار `SOAR_PANEL_VERSION=1.16.3` را در فایل `.env` نصب ذخیره کنید.
