# WhiteDNS Server Management 1.16.5

- بعد از تأیید یا رد تکی و گروهی در تلگرام، همان پیام نتیجه و فهرست به‌روز درخواست‌ها را نشان می‌دهد. درخواست‌های بررسی‌شده از صف خارج می‌شوند.
- فهرست پس از ثبت تصمیم و پیش از آماده‌سازی کانفیگ تازه می‌شود. اگر سقف صدور پر باشد، درخواست در صف می‌ماند و مدیر علت را در همان پیام می‌بیند.
- اگر درخواست قبلاً بررسی شده یا منقضی شده باشد، بازکردن دکمهٔ قدیمی، فهرست جاری را نشان می‌دهد.

### نصب پیش‌انتشار

روی سروری که پنل با systemd نصب شده، این دستور را اجرا کنید.

```bash
sudo /usr/local/bin/soar-panel maintenance --action update --version 1.16.5
```

برای Docker Compose، دستور زیر را در پوشهٔ نصب اجرا کنید.

```bash
SOAR_PANEL_VERSION=1.16.5 docker compose up -d --pull always
```

برای ثابت‌کردن نسخهٔ Docker، مقدار `SOAR_PANEL_VERSION=1.16.5` را در فایل `.env` نصب ذخیره کنید.
