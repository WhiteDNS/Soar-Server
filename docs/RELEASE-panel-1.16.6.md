# WhiteDNS Server Management 1.16.6

- مالک و مدیر کامل ربات می‌توانند از «داشبورد کانفیگ رایگان ← محدودیت‌های سرویس رایگان» سقف ثبت، صدور، تعداد حساب‌ها و بودجهٔ اتصال‌ها را تغییر دهند. همان منو تنظیمات مهلت‌ها، اعتبارسنجی و صف‌های تلگرام را هم دارد.
- صفحهٔ «آمار» مصرف ظرفیت را جداگانه نشان می‌دهد. اگر صدور ممکن نباشد، پیام بررسی درخواست دلیل آن را مشخص می‌کند.
- از فرم «ویرایش پلن» می‌توان پذیرش خودکار را برای هر پلن جداگانه فعال کرد. حالت پیش‌فرض دستی است. پذیرش خودکار برای درخواست‌های تازه‌ای اجرا می‌شود که تأیید شده‌اند و ظرفیت کافی دارند. اگر ظرفیت کافی نباشد، درخواست در صف بررسی مدیر می‌ماند.

### نصب پیش‌انتشار

روی سروری که پنل با systemd نصب شده، این دستور را اجرا کنید.

```bash
sudo /usr/local/bin/soar-panel maintenance --action update --version 1.16.6
```

برای Docker Compose، دستور زیر را در پوشهٔ نصب اجرا کنید.

```bash
SOAR_PANEL_VERSION=1.16.6 docker compose up -d --pull always
```

برای ثابت‌کردن نسخهٔ Docker، مقدار `SOAR_PANEL_VERSION=1.16.6` را در فایل `.env` نصب ذخیره کنید.
